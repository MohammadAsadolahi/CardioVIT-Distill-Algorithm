# CardioVIT-Distill

**CardioVIT-Distill: Hardness-Aware Data Splitting and Knowledge Distillation for Robust Myocardial Abnormality Detection**

> **Publication status:** The manuscript is currently under peer review. The source code and methodological details will be made publicly available in this repository upon publication of the paper.

## Overview

This repository accompanies **CardioVIT-Distill**, a study investigating hardness-aware data splitting and knowledge distillation for myocardial abnormality detection using cardiac magnetic resonance (CMR) imaging.

The research focuses on Vision Transformers, lightweight hybrid CNN–ViT models, teacher-guided training, and explainable medical image analysis, with myocarditis detection as an application of interest.

## Code and Documentation

This repository currently serves as the project's public reference point during peer review. Upon publication of the paper, it will be updated with:

- The source code for CardioVIT-Distill.
- Methodological details and accompanying implementation documentation.
- A link to the published paper and citation information.
